# Temperature-monitoring-system-
A temperature monitoring system simulated using Tinkercad. The project uses a temperature sensor connected to an Arduino to measure the surrounding temperature. The Arduino processes the sensor readings and displays the temperature value, allowing real-time monitoring in a virtual environment.
Components used:
1) ARDUINO UNO LM35
2) TEMP36 Temperature sensor
3) 16*2 LCD display
4) jumper wires
5) USB cable
